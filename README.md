# AI UAT Script Generator

An AI-powered tool that generates User Acceptance Testing (UAT) scripts from Business Requirement Documents (BRDs).

## What it does

Upload a BRD and automatically generate:

- Functional Test Cases
- Negative Test Cases
- Boundary Test Cases
- Acceptance Criteria

## Why I built this

As an Applications Analyst, I often worked with UAT documentation. This project demonstrates how AI can help generate structured test scripts from business requirements, reducing manual effort while maintaining consistency.
